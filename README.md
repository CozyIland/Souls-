# Aschenblatt (Arbeitstitel)

Souls-like im Anime-Stil: ein Karten-Magier in einer postapokalyptischen Stadt.
Plan und Roadmap: [PROJEKTPLAN.md](PROJEKTPLAN.md).

## Stand: Schritt 0 – Fundament
Testgelände (verfallene Kreuzung), Platzhalter-Magier, Laufen, Rennen, Ausweichrolle, Ausdauer,
freie Kamera und Zielerfassung auf Übungspuppen.

| | Xbox-Controller | Tastatur & Maus |
|---|---|---|
| Laufen | linker Stick | WASD |
| Kamera | rechter Stick | Maus (ins Bild klicken) |
| Rolle | B tippen | Leertaste |
| Rennen | B halten | Shift |
| Ziel erfassen / lösen | R3 (rechten Stick drücken) | Q / Mausrad-Klick |
| Ziel wechseln | rechten Stick zur Seite schnippen | – |
| Pause | Start | Esc |

## Spielen
